4.1A criterion the golden itself fails

Fails the taskRubric Criteria - Overall Rubric Quality

The mistake

Your golden fails a criterion that is wrong about the task: a rule only the Desired Outcome states, a phrase at a different length than the golden renders, or a file the inputs lack.

Do this instead

Rewrite an unsupported criterion, or fix the golden with a Leg B cleanup turn at intent level. Move an outcome only rule into the prompt and run both legs again, or drop it.

Why it matters

The golden has to pass the complete rubric set. A criterion the golden fails is a broken criterion, not a broken golden, so a correct run gets marked Not Present. Each one counts as Major, and Majors on more than 10% of your criteria fail the task outright. The commonest cause is a rule that lives only in the Desired Outcome: the agent never sees it, so a criterion resting on it fails a run that did exactly what it was told, and it catches your own golden too.
