4.2Criteria a correct run cannot pass, or a wrong one can

Costs pointsRubric Criteria - Overall Rubric Quality

The mistake

A criterion stricter than its source fails correct runs: it pins a figure the source leaves open, picks one answer of several, insists on one of two sources, or scopes to a part of the deliverable that lacks the values. A looser one passes wrong runs.

Do this instead

Grade the shape of an answer the source leaves open, accept either source, scope to where the values appear, and add bounds: exactly, only, between.

Guidelines · 5.1 Rubric Fundamentals

Guidelines · 5.6 How the Client Defines Rubric Issue Severity

The criterion can be rated, but it is built wrong: redundant, vague, misplaced, misweighted or pointed at the wrong thing.

Moderate, which fails the task above 15%. Its named types include Overlapping or Redundant, Overfitting and Underfitting, Incorrect Weights, Block Bleed and Miscategorized.

Guidelines · 5.1 Rubric Fundamentals

If a criterion references a literal that does not actually exist in the source, no run can satisfy it, and it must be treated as an Incorrect Criteria issue.
Why it matters

The rubric exists to separate a correct run from an incorrect one. A criterion a correct run cannot satisfy marks down the runs that did the work, and it usually catches your own golden, because the golden followed the evidence while the criterion followed your memory. A criterion with no ceiling lets a run that also took the distractors pass, so the traps the task was built around cost nothing. Overfitting and Underfitting is a named Moderate issue; a literal that exists nowhere in the source is Incorrect Criteria.
