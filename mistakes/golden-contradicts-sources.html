6.1The golden states something its own sources contradict

Costs pointsGolden Solution - Artifact Completeness

The mistake

The golden states a value its source, or its own page, contradicts, often one left behind when the rest of the page moved. Nothing graded catches it.

Do this instead

Before you complete Leg B, send Model B a cleanup turn that points at the area, never the value, then check every place the value appears.

Why it matters

The golden is the reference point for the subjective evaluation and the pairwise comparison, so a wrong value in it is graded as correct and a run that reads the source properly is marked down. Every factual claim in it has to be grounded in the inputs: an inaccuracy or an ungrounded claim is a Minor Golden Defect, and it costs points. Where a criterion grades the same detail, either your golden fails it or, if the criterion was written from the golden, a correct run does.

The assumptions panel documents the extraction rules and holiday removals. One honest flag carried in the UI: handovers were only circled Aug–Oct on your sheet, so the 7 is what's *marked* — if custody actually continues biweekly all year, the Friday exposure is larger, which the Wed–Fri preset already hints at.
