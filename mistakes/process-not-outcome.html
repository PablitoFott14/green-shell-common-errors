2.1A process criterion where a completion criterion belongs

Costs pointsInside the cap: Avoidable Process Criteria · above 20%: Process Over Cap, an automatic fail

The mistake

A criterion grades on the Trajectory what the agent read, reconciled or concluded on the way, when the value it protects lands in the deliverable and could be graded there.

Do this instead

Write the completion version first: grade the value, classification or decision where it lands in the artifact, the state change or the final message. Keep a process criterion only where no deliverable can show the failure, and count them.

Catch it in your own task

Ask of every Trajectory, Agent Behavior and Tool Use criterion: could the deliverable be perfect and this still fail? If so, find the line of the deliverable that shows the same thing and grade that line instead.

Where the correct guidance is written

Section titles as they print, so you can search for them in the document.

Guidelines · 5.1 Rubric Fundamentals

MANDATORY: at least 80% of the objective criteria grade completion. At most 20% grade process. If the process share is above 20%, the task fails automatically.

Process means Tool Use, Agent Behavior, any Trajectory target and narration of the agent's own work.

Guidelines · 5.1 Rubric Fundamentals

Could the deliverable be perfect and this criterion still fail? Then it is process. Rewrite it as completion whenever you can.

Guidelines · 5.1 Rubric Fundamentals

Round down: with 12 objective criteria, at most 2 can be process (20% of 12 is 2.4).

The subjective block is not part of the count.

QC spec · Rubric Criteria - 80/20 Outcome Split (Process Over Cap)

Process criteria are within the cap, but at least one could have been written as a completion criterion (the value it protects can be graded where it lands in the deliverable).

Non-Fail - Avoidable Process Criteria: inside the cap, it still costs points.

Guidelines · 5.4 Category & Evaluation Target

Prefer grading the value it read in the deliverable (Task Completion); write this version only when the deliverable cannot show it.

The Agent Behavior row, which also counts toward the 20% process cap.

Why it matters

The client grades completion. More than 20% process criteria in the objective block, counted and rounded down, fails the task automatically as Process Over Cap. Inside the cap, a process criterion whose value could be graded where it lands still costs points, and it usually grades the same evidence twice.
