4.2A subjective criterion outside Task Completion

Costs points7.4 Categories and Evaluation Targets for Subjective Rubrics

The mistake

A criterion in the subjective block is tagged Instruction Following, or any category but Task Completion, as if the render could be disobeyed.

Do this instead

Every subjective criterion is Task Completion on the Final Answer Artifact, with User-Facing Message only in the rare case the Guidelines allow. If the prompt asked for it, it is objective only.

Catch it in your own task

Sort the subjective block by category. Anything that is not Task Completion is either tagged wrong or sitting in the wrong block.

Where the correct guidance is written

Section titles as they print, so you can search for them in the document.

Guidelines · 7.4 Categories and Evaluation Targets for Subjective Rubrics

Task Completion is the only valid category for subjective rubrics. Instruction Following is excluded by design, not by preference: if a requirement is explicitly stated in the prompt, it belongs in the objective block.

Guidelines · 7.1 Writing Subjective Rubrics

If anything related to the render is asked in the prompt, it requires an objective rubric ONLY.

Guidelines · 5.6 How the Client Defines Rubric Issue Severity

The criterion can be rated, but it is built wrong: redundant, vague, misplaced, misweighted or pointed at the wrong thing.

Moderate, which fails the task above 15%. Its named types include Overlapping or Redundant, Incorrect Weights and Miscategorized.

Guidelines · 5.6 How the Client Defines Rubric Issue Severity

A Moderate issue is downgraded when fixing it would leave every Present and Not Present judgment in the task exactly the same.

Minor, which fails the task above 20% of the criteria. A weight or a category fixed on its own changes no rating.

Why it matters

Instruction Following is excluded from the subjective block by design: a requirement the prompt states belongs in the objective block, and a property it does not state is Task Completion. Category and target shape how the rubric data reaches the client.

Need a hand before this sale ends. I found the drawing tablet I need for my design class at Best Buy and copied the shelf tag into my notebook, that's IMG_4471.jpg. That night I looked it up on my phone and wrote down every listing I found, then checked again a couple days later, those notes are IMG_4478.jpg, IMG_4479.jpg and IMG_4502.jpg. I also started a comparison page, price_compare_draft.html, but ran out of steam and the buttons don't even do anything. What I want to know is if I can get the exact same unit cheaper online, but I only want to count sellers that ship to my place in Raleigh, have it in stock right now, and are the retailer itself, not some third party marketplace seller. For each one give me the delivered price, so item plus shipping the way it would actually get charged to me, with Raleigh sales tax on top, and how much I really save compared to what I'd pay at Best Buy for it right now. Don't go looking stuff up on the web, prices move around, the listings I care about are the ones in my notes. Put it all in wacom_price_check.html and make it an actual interactive page, not just a table. I want to see pass or fail on each of those three rules for every seller instead of you assuming. The ones that don't make the cut should still be in there but hidden by default, with the rule they failed, and same if a listing turns out not to be the same unit, keep it hidden and tell me why. Up top just tell me who to buy from, the delivered price and what I save, plus who's next best in case that one sells out.
