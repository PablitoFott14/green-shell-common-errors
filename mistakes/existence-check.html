2.2A criterion that only checks a file exists

Fails the taskRubric Criteria - Existence Check

The mistake

A criterion passes as soon as a file, section, column or record is there, whatever it contains. A check on the filename alone is the same thing in another form.

Do this instead

Grade what the file records. A criterion on a value inside the file already proves it exists, under the name the prompt gave it.

Catch it in your own task

Ask of each criterion: could it pass on a file full of wrong content? If it could, rewrite it to grade the content or delete it.

Where the correct guidance is written

Guidelines · 5.1 Rubric Fundamentals

Existence is implied by any criterion that grades content: if report.md records the correct total, report.md exists. A criterion that only checks existence fails the task automatically (section 5.6).

QC spec · Rubric Criteria - Existence Check

Automatic fail, in either block. Disguised forms: 'includes a section titled X', 'contains the columns A, B, C', 'produced a chart', 'the email was sent' with no content. Test: could the criterion pass on a file full of wrong content?

Why it matters

An existence check is an automatic fail, in either block, regardless of how many other issues the rubric has. It is never valid at any weight, and it adds nothing: every criterion that grades the content of a file already shows the file is there.
