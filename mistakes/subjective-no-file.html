Catch it in your own task

With more than one file, every subjective criterion contains a filename.

Where the Green Shell guidance is written

Section titles as they print in the Green Shell Guidelines and QC spec, so you can search for them.

Guidelines · 5.1 Rubric Fundamentals

Include the exact expected value, filename, classification, decision, or other fact needed to determine whether it is Present or Not Present.

Self-contained. Section 7.1 applies these fundamentals to subjective rubrics exactly as written.

Guidelines · 7.1 Writing Subjective Rubrics

The element makes the criterion self-contained by telling the reviewer where to look; the property defines exactly what gets scored.

Guidelines · 7.1 Writing Subjective Rubrics

Anchor each criterion to one identifiable element and one visible property: Point to something that can clearly be located in the artifact, then evaluate a single observable characteristic of it.
Why it matters

The evaluation target only says Final Answer Artifact, not which file. Once a task ships two deliverables, “the table” or “each scene” stops identifying anything, and two graders can score the same run against different files. The element is what makes a criterion self-contained, by telling the reviewer where to look, and naming the file costs nothing.
