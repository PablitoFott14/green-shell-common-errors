3.3A category that does not say what the criterion grades

Costs pointsMiscategorized

The mistake

Criteria the model can get wrong are tagged Instruction Following, often next to the same kind of check tagged Task Completion, so the category stops saying what kind of check it is.

Do this instead

Decide by the Guidelines' question: discoverable from the materials, or only knowable by being told? A verdict the model reads off the inputs is Task Completion; Instruction Following is a stipulation it can only disobey.

What it should have been

How it breaks the standardThe Guidelines split the two with one question: discoverable from the materials, or only knowable by being told? Every one of these verdicts is read off the notes or the universe, so a model that misreads CTL6100WLE0 is wrong, not disobedient.

The rule it breaksGuidelines · 5.4 Category & Evaluation Target You can only be disobedient at it, never wrong. That is Instruction Following. A verdict a model can get wrong is Task Completion.

Catch it in your own task

Sort the objective block by category and read each group: every Instruction Following row should be something no expert could guess without being told, and same kind checks should share a category.

Why it matters

Category and Evaluation Target shape how the rubric data is structured, delivered to the client and interpreted downstream. Miscategorized is one of the named Moderate issues, downgraded to Minor when fixing it changes no Present or Not Present judgment.
