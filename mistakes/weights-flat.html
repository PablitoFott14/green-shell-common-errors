3.3Weights that do not separate difficulty from lookup

Costs pointsRubric Criteria - Overall Rubric Quality

The mistake

Weights that ignore difficulty: a cross source derivation weighted like a direct read, or one operation at 5 in one row and 3 in the next.

Do this instead

Weight by axis count, never importance. A lookup at 5, or a chained derivation at 1, is a two level miss.

Where the Green Shell guidance is written

Section titles as they print in the Green Shell Guidelines and QC spec, so you can search for them.

Guidelines · 5.2 Rubric Weights

Weight is difficulty, never importance. How hard the criterion is to satisfy, or for a negative, how tempting the failure is.

Guidelines · 5.2 Rubric Weights

A requirement can be critical to the task and still be +1 because meeting it is mechanical.

Guidelines · 5.6 How the Client Defines Rubric Issue Severity

The criterion can be rated, but it is built wrong: redundant, vague, misplaced, misweighted or pointed at the wrong thing.

Moderate, which fails the task above 15%. Its named types include Overlapping or Redundant, Overfitting and Underfitting, Incorrect Weights, Block Bleed and Miscategorized.

Why it matters

The scale exists to separate discovery from lookup. When it does not, the final score says nothing about whether the model did the hard part, and a run that nails every lookup while missing every derivation still scores well. Incorrect Weights is one of the named Moderate issues.
