6.2The five minute close out nobody runs

Fails the taskGolden Solution - Artifact Completeness · Trajectory - Golden/Preferred Run Selection

The mistake

Cheap checks, often skipped: stray files in the golden, a filename spelled two ways, a golden that stops short of the prompt, no preferred run, and criteria a grader must decode. A missing named file fails the task; a literal that matches nothing is Incorrect Criteria; the rest cost points.

Do this instead

Remove anything the prompt does not name, clean build notes out with a Leg B cleanup turn, star the preferred run, match the prompt's spelling, and copy every literal in a criterion from its source.

Why it matters

Artifact Completeness wants every file the prompt names present and spelled exactly as the prompt spells it, artifacts only, no narration: a script or build note left with the golden shows how the answer was reached. A missing star costs points on its own, and with several runs and none preferred there is no reliable way to tell which run is the right one. A criterion citing a value or a filename that exists nowhere cannot be satisfied by any run, and a grader who has to work out what a clause means is making the judgment the clause was supposed to make.

_cache = {}
def font(kind, size):
    key = (kind, size)
    if key not in _cache:
        f = {"sans":"DejaVuSans.ttf","bold":"DejaVuSans-Bold.ttf",
             "mono":"DejaVuSansMono.ttf","monob":"DejaVuSansMono-Bold.ttf"}[kind]
        _cache[key] = ImageFont.truetype(os.path.join(FONTDIR, f), size)
    return _cache[key]

# ---- draw helpers --------------------------------------------------------
def canvas(bg=BG):
    im = Image.new("RGB", (W, H), bg)
    return im, ImageDraw.Draw(im)

def text(d, xy, s, fnt, fill=INK, anchor="la"):
    d.text(xy, s, font=fnt, fill=fill, anchor=anchor)

def measure(fnt, s):
    return fnt.getlength(s)

def wrap(d, s, fnt, x, y, maxw, fill=INK, leading=1.35, center=False):
    words, lines, cur = s.split(), [], ""
    for w in words:
        t = (cur + " " + w).strip()
        if measure(fnt, t) <= maxw:
            cur = t
        else:
            if cur: lines.append(cur)
            cur = w
    if cur: lines.append(cur)
    lh = int(fnt.size * leading)
    for i, ln in enumerate(lines):
        d.text((x, y+i*lh), ln, font=fnt, fill=fill, anchor=("ma" if center else "la"))
    return y + len(lines)*lh

def panel(d, box, fill=PANEL, outline=None, width=2, radius=22):
    d.rounded_rectangle(box, radius=radius, fill=fill, outline=outline, width=width)

def chip(d, xy, s, fill, textcol=(15,16,18), fnt=None, pad=(22,12)):
    fnt = fnt or font("bold", 34)
    tw = measure(fnt, s); x, y = xy
    box = (x, y, x+tw+pad[0]*2, y+fnt.size+pad[1]*2)
    d.rounded_rectangle(box, radius=(box[3]-box[1])//2, fill=fill)
    d.text((x+pad[0], y+pad[1]-2), s, font=fnt, fill=textcol)
    return box

def label_masked(d, cx, cy, s, fnt, fill, pad=12, bg=BG):
    """Center a label at (cx, cy top) with a background box so any line behind it stays readable."""
    w = measure(fnt, s)
    d.rectangle((cx-w/2-pad, cy-4, cx+w/2+pad, cy+fnt.size+8), fill=bg)
    d.text((cx, cy), s, font=fnt, fill=fill, anchor="ma")

         "S6  SN 93441234   •   Baseline BL-1–BL-2  =  812.000 ft   •   feet to three places",

## Office rule — baseline check
Any instrument back from a bench gets this **before it goes out on a job**.

1. Set **PPM off the shop gauge** before the first shot — every time.
2. **Three sets**, horizontal distance (HD), **feet to three places**.
3. A set **> 0.005 ft** off the other two = a strike (a bump, or PPM). **Strike it, shoot it again. Never average a strike.**
4. **Mean of three, less 812.000:**
   - inside **0.010 ft → GOOD** (it stays / it goes out)
   - over **0.010 ft → IT GOES BACK**
5. **Write it down:** date, instrument + SN, conditions, PPM, the three sets, mean, deviation, the call, initials.

## Why our 0.010 ft, not the manufacturer sheet
The service sheet spec is **±(2 mm + 2 ppm)**, prism mode. Worked at 812.000 ft that is **≈ ±0.008 ft**
(2 mm ≈ 0.007 ft + 2 ppm ≈ 0.002 ft). That is the instrument alone on the shop's 3-pillar bench.
Our **±0.010 ft** is a field limit that covers the whole setup on our line — tripods both ends,
tribrachs, centering, PPM, and the baseline itself. **Judge against 0.010 ft. Not the brochure.**
