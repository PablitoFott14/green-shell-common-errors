4.4The same check written twice

Costs pointsRubric Criteria - Overall Rubric Quality

The mistake

Two criteria decided by the same evidence: one inside a broader one, a negative mirroring a positive, or a subjective criterion restating an objective value.

Do this instead

Keep one, the broader where one swallows the other. A subjective restatement keeps only its presentation property, or goes.

Where it happened in Red Shell

One real Red Shell task. Each shows the spot and what it should have been; click any line to open the task there.

What it should have been

Criterion 2+5Keep it
Criterion 9Delete it
if criterion 2 passes, criterion 9 cannot fail

How it breaks the standardThe four files criterion 2 names leave out both inspection maps, so an index that passes criterion 2 passes criterion 9. Keeping the maps off the index is worth weight 10 across two rows, and an index that keeps one map loses both. The golden passes both, so nothing flags it; the duplicate costs points.

The Green Shell rule it breaksGuidelines · 5.3 Positive and Negative Distribution by defining the complete valid set A closed list already keeps the rest out; a second criterion counts it twice.

Catch it in your own task

Name the evidence that decides each criterion: two on the same line are duplicates.

Where the Green Shell guidance is written

Section titles as they print in the Green Shell Guidelines and QC spec, so you can search for them.

Guidelines · 5.3 Positive and Negative Distribution

This directly captures the intent behind “Do not include clients who purchased after March 2026” by defining the complete valid set.

A closed list already rules the rest out: no separate criterion is needed for what it excludes.

Guidelines · 5.6 How the Client Defines Rubric Issue Severity

The criterion can be rated, but it is built wrong: redundant, vague, misplaced, misweighted or pointed at the wrong thing.

Moderate, which fails the task above 15%. Its named types include Overlapping or Redundant, Overfitting and Underfitting, Incorrect Weights, Block Bleed and Miscategorized.

QC spec · Rubric Criteria - Subjective Block Scope

The subjective block contains 2+ deterministic value checks, existence checks or process checks that belong to the objective block.

The failing option, a Deterministic Value Scope Violation.

Why it matters

Redundant criteria double weight one outcome, so a single slip costs the run twice. A closed list already rules everything else out, so a second criterion excluding one item counts it again. A subjective block that repeats objective values also stops doing its own job, which is grading how the artifact reads and looks, and two such value checks there fail the task.
