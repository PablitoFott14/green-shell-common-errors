3.1The same check written twice

Costs pointsOverlapping or Redundant · Not Atomic

The mistake

One criterion restates what others already grade, often a long Trajectory criterion that bundles the whole answer key, so a single slip costs the run several times.

Do this instead

One evaluable outcome per criterion, graded once, where it lands. If a criterion's parts could pass separately, split it; if another criterion already decides it, delete it.

How it breaks the standardOne misread, such as the Brooks delivery date, now fails criterion 7 and criterion 21 together, so the run pays twice for one slip. Bundling a dozen decisions into one row also means its rating cannot say which one failed.

The rule it breaksGuidelines · 5.6 How the Client Defines Rubric Issue Severity The criterion can be rated, but it is built wrong: redundant, vague, misplaced, misweighted or pointed at the wrong thing. Overlapping or Redundant is one of the named Moderate types.

Catch it in your own task

For each criterion, find the evidence that decides it. Two criteria decided by the same evidence are one check counted twice.

Where the correct guidance is written

Section titles as they print, so you can search for them in the document.

Guidelines · 5.1 Rubric Fundamentals

Each criterion should capture one clear grading signal tied to the task intent. What matters is whether all parts of the criterion contribute to the same evaluable outcome. If you have doubts, separate criteria.

Guidelines · 5.6 How the Client Defines Rubric Issue Severity

The criterion can be rated, but it is built wrong: redundant, vague, misplaced, misweighted or pointed at the wrong thing.

Moderate, which fails the task above 15%. Its named types include Overlapping or Redundant, Incorrect Weights and Miscategorized.

QC spec · Rubric Criteria - 80/20 Outcome Split (Process Over Cap)

Process criteria are within the cap, but at least one could have been written as a completion criterion (the value it protects can be graded where it lands in the deliverable).

Non-Fail - Avoidable Process Criteria: inside the cap, it still costs points.

Why it matters

Overlapping or Redundant criteria are a Moderate issue, and a criterion that bundles unrelated decisions is Not Atomic. Either way the run pays twice for one slip, and two to four issues of any severity can be enough to reject a task.
