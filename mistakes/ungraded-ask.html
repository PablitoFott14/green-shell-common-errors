2.3An ask the rubric never grades

Costs pointsMissing Criteria

The mistake

The prompt asks for something, here even the assigned Execution target, and no criterion checks it, so a run that ignores it scores exactly like one that does it.

Do this instead

Walk the prompt once and tick off every ask: anything you can tick needs a criterion. Where the deliverable ends up is an ask too, whenever the prompt says it.

Guidelines · 5.6 How the Client Defines Rubric Issue Severity

The grade comes out wrong. Something the answer depended on is never checked, or something is checked that a correct run cannot satisfy.

Major, which fails the task above 10% of the criteria. Missing Criteria, Critical is one of its named types.

Guidelines · 1.1.2 Rest of the Parameters

Where the deliverable ends up and any limit on the run, such as nothing sent. State both in the prompt, or they cannot be graded.

Why it matters

A requirement nothing checks is a Missing Criteria issue: the grade comes out wrong because something the answer depended on is never checked. When the requirement is critical it is Major, and Major issues above 10% of the criteria fail the task.
