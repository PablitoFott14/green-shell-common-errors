How status is decided — the same test on all three. Read = I opened the file and read its title/axes/layout. Confirmed = that opened file matches a same-piece sign-off — someone clearing that same export for the story — with nothing later flagging the folder copy stale or the counts old. Who clears it doesn't matter; clearing that export does. A “got it” on a different piece doesn't count. I looked for a same-piece sign-off across every channel (#graphics, #citydesk, #data-team and the DMs), not just the export thread. Where Slack and a file disagreed, the file won.
