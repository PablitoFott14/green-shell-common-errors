      Instructor / QA notes — everything re-checked against the source slides (delete before publishing)

      Authority = the teacher's source video (basics.mp4) slides + narration. Where the demo clip, the notes PDF, or the clip's quiz picks disagreed with the source, the source wins:

      • Heart rate = 75 bpm. Source slide reads "Steps of cardiac cycle (for 75 bpm heart rate)." The notes PDF's "70 bpm" is wrong.
      • Passive filling = ~70% everywhere — panels, chips, and the Q3 option. Source slide says "filling passively to roughly 70%"; the demo's 80% (and the clip's ~80% pick) was wrong, so the quiz option was changed to ~70%.
      • T wave = ventricular repolarization. Demo legend said "atrial" — wrong (source ECG slide).
      • Q2 = the QRS complex. Source ECG slide: "atrial systole extends until the QRS complex, at which point the atria relax" — atrial repolarization is masked in the QRS. Clip's "P wave" pick was atrial depolarization.
      • Q1 = AV valves · S1. Source heart-sounds slide: S1 "lub" = AV valves close, S2 "dub" = semilunar valves close. Clip picked "aortic · S1" (wrong).
      • Cardiac-output note = ~250%. Source CO slide: "Heart rate can increase by 250%." The demo said 200%.
      • Tricuspid auscultation = 4LICS (demo chip said 2LICS, which is the pulmonary point). Also: source table lists aortic = 2RICS (the notes PDF's 3RICS is wrong) — corrected in captions.pdf.
